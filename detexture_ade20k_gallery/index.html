This page uses the public detexture_ADE20K crop benchmark. Direct metrics score GT texture A as the canonical foreground. Invariant metrics allow complement matching and ignore overlap and void pixels by scoring only on exclusive-valid pixels. The public comparison is validation-only (56 crops) because the released TextureSAM checkpoint was trained on ADE20K. Matched common-54 invariant results: TextureSAM 0.4715 / 0.3306, ArchiTexture 0.5043 / 0.3762.

Diagnostic Views

Dictionary: How to Read This Page
Direct metrics
IoU and ARI against GT texture A, which is the canonical foreground side for this route.
Invariant metrics
IoU and ARI after allowing complement matching, computed only on exclusive-valid pixels where GT texture A and GT texture B disagree.
GT texture A / B
The two curated region masks released with the public DeTexture validation crop benchmark.
TextureSAM union view
A visualization-only union of TextureSAM's mask bank. The reported TextureSAM numbers still come from the full mask bank, not from this union image.
TextureSAM miss
The public TextureSAM checkpoint emitted no masks for this crop. ArchiTexture still returns one region.
Overlap / void pixels
Pixels where both GT masks are active or both are inactive. They are ignored by this evaluator.
