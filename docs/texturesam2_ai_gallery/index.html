Dictionary: How to Read This Page
Official IoU
RWTD official two-partition IoU score for the selected final mask.
Official ARI
RWTD official adjusted Rand index for the selected final mask.
Baseline scored mask
The exact baseline mask that is scored in the audit protocol.
Core mask
Conservative mask before rescue switching.
Final mask
Selected output after decision layer commits.
Mitigation final
Output from the stricter mitigation policy for comparison.
Decision margin
Top-1 vs top-2 decision score gap; lower values indicate higher ambiguity.
Rescue confidence
Model confidence associated with rescue switching behavior.
Top-k recoverable
Whether a better candidate exists in top-k even if final output is wrong.
All candidates overlay
All candidate masks overlaid together on the image; shows full suggestion spread.
Proposal support (pixel frequency)
How many proposals support each pixel; hotter means more proposal agreement.
