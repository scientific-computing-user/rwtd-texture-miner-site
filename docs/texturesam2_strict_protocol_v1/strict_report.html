Abstract

Question: How do we turn fragmented SAM texture proposals into robust RWTD masks, without RWTD leakage?

Incentive: RWTD evaluation rewards accurate texture regions and penalizes fragmentation (ARI).

Intuition: keep high-recall proposals, then use PTD-trained AI consolidation; only switch to aggressive multi-region behavior when low-coverage evidence is clear.

Main thread: PTD-only learned modules (v3, v8) + conservative v9 gate to preserve robustness while fixing under-coverage failures.

Leakage-Safe Protocol

Leakage statement: RWTD labels are used only for the final metric computation step. They are not used to train weights and not used for parameter search.
  • External training data: PTD only (246,285 images, 56 texture classes).
  • RWTD role: final test set only.
  • Frozen pipeline: configuration and learned models fixed before final RWTD scoring.

Step-by-Step Pipeline (Easy Words)

  1. SAM generates candidate masks from official TextureSAM η≤0.3 settings.
  2. PTD texture embeddings + graph merge produce coherent components (v3).
  3. v8 partition model proposes multi-region unions when texture class repeats across disconnected regions.
  4. v9 conservative gate keeps v7 by default and only switches to v8 when proposal-union coverage evidence indicates under-segmentation.
  5. Final mask is emitted per image with no RWTD-label tuning.
