Abstract

Question: how can SAM proposals be converted into one coherent texture mask without leaking RWTD test labels into training or tuning?

Incentive: RWTD is binary segmentation and strongly penalizes fragmentation, so region coherence matters as much as recall.

Core idea: keep high-recall proposal generation, then solve fragmentation with texture-aware consolidation trained on PTD-only supervision.

Main thread: diagnose fragmentation, train consolidation on PTD-derived data, freeze pipeline, evaluate RWTD once.

Strict Protocol

Leakage statement: RWTD labels are used only for final metric computation. External training data is PTD only.
  1. Train texture/consolidation components on PTD and PTD-derived synthetic segmentation tasks.
  2. Freeze learned weights and thresholds before RWTD final run.
  3. Run one-shot RWTD evaluation and report mIoU/ARI.

Pipeline Stages

  1. High-recall proposal bank: SAM prompt-masks (v5 bank) provide many candidate fragments per image.
  2. Texture descriptors: each candidate gets texture features (handcrafted/PTD encoder based).
  3. Texture-aware merging: adjacent, texture-consistent fragments are consolidated.
  4. Single-mask selection: a coherence objective picks one final connected binary foreground.

Prompt Mechanics and Candidate Count

  • v2/v3/v4/v5 prompts: versioned prompt-template families designed to diversify candidate masks.
  • Why diverse prompts: better proposal coverage before consolidation reduces miss risk.
  • Strict PTD-v2 setting: uses the frozen v5 prompt-mask bank for protocol control.
  • Average candidate count: 25.875 proposal masks per image.
